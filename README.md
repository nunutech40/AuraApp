# BidadariMeter 🧚‍♀️✨ (AuraApp)

**BidadariMeter (AuraApp)** adalah aplikasi *mobile* iOS (iPhone) yang dirancang khusus untuk mengukur tingkat "Aura", "Karisma", dan "Vibe" dari sekumpulan foto wajah secara otomatis melalui Galeri HP. 

Aplikasi ini didesain sebagai *showcase* portofolio *Mobile Development* tingkat tinggi, menggunakan antarmuka **Flutter** yang memukau (animasi *Cinematic*, *Glassmorphism*) yang disambungkan secara *Native* ke otak komputasi **Swift (Apple Vision Framework)**.

> 🤫 **SSSTTT... RAHASIA!**
> Meskipun secara *front-end* dan pemasaran kita bilang ini mendeteksi "Aura" dan "Karisma", *engine* utama di lapisan iOS murni menggunakan komputasi matematika tingkat tinggi (**Algoritma Rasio Emas / *Golden Ratio***). Aplikasi ini menghitung tingkat simetris wajah berdasarkan titik-titik koordinat geometri, namun hasilnya disamarkan sebagai "Skor Magis Aura". 

## Fitur Utama
*   **Multi-Image Gallery Picker:** Pilih banyak foto sekaligus langsung dari galeri iPhone.
*   **Decoupled Architecture:** Tampilan berjalan lancar di Flutter (Dart), sementara kalkulasi berat berjalan secara *offline* dan rahasia di Native iOS (Swift) lewat `MethodChannel`.
*   **Cinematic Gimmick:** Dilengkapi animasi *Laser Scanner* dan teks ala mesin tik / *hacker* saat foto diproses untuk *wow factor* pembuatan konten sosmed.
*   **Aura Leaderboard:** Hasil akhir berupa *Card UI* yang mengurutkan foto dengan nilai "Aura" terbaik.
